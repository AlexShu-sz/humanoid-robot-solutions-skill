# 豆包工作平台执行说明

本文件是 `industrial-robot-solution` 在**豆包工作**（Linux 云端工作环境）里的执行说明，打包时由 `build_skill.py` 复制到技能包的 `references/平台执行说明.md`。

业务规则以 `references/` 下三份共用规则为准：`方案制作与交付规则.md`、`需求分析与章节规划规则.md`、`版式锁定与复跑校验.md`。共用规则写的是通用做法；本文只补**本平台怎么落地**（模板路径、脚本命令、字体、交付、在线版边界），不改变业务判断。

## 与共用规则的对应关系

| 共用规则中的表述 | 本平台的实际做法 |
|---|---|
| 「用户未指定母版时，在当前项目或已授权的文件来源中查找模板」 | 用技能自带 `assets/人形机器人方案_PPT模板_V1.0.0.pptx`；用户本次明确上传了模板时优先用上传件 |
| 「有可用 PPT 生成能力时，按宿主适用流程生成并导出可编辑 pptx」 | 用 python-pptx 在模板副本上改内容，产出原生可编辑 `.pptx`，不走 HTML/图片拼版 |
| 「当前宿主只能生成内容时，输出逐页制作稿」 | 仅当用户明确要**飞书在线幻灯片**时走制作稿路径，见下文「在线幻灯片」 |
| 「中文微软雅黑、西文 Arial」 | 文件里照写这两款字体；本机无此字体，预览由 Noto Sans CJK 替代，只影响预览 |
| 回归校验命令 `python scripts/check_ppmt_layout.py ...` | 用 `python3 scripts/check_ppmt_layout.py`，`--template` 省略时自动取 `assets/`，仓库内运行回落 `templates/`；另加逐页渲染 `scripts/render_pages.py` |
| 「视频用宿主的视觉能力或可用工具抽取关键帧」 | 用本机 ffmpeg 按时间点抽帧，见下文 |
| 「当前平台支持生成工作簿时导出客户补充信息表」 | 用 `scripts/make_supplement_xlsx.py` 生成 xlsx（表头、列宽、行高、冻结窗格统一，客户填写列留空上色） |
| 「从本次附件或团队资料库打开原件」 | 本技能不自带资料库：`参考资料/机器人本体|末端|历史解决方案|报价表/` 按**当前项目目录**解析，缺目录就记缺项，不编造型号/价格/案例 |

| 能力 | 现状 | 用法 |
|---|---|---|

## 目录与文件约定

- 交付根目录是当前项目目录；中间物放 `<项目目录>/_方案工作/<项目名>/`：`内部项目稿.md`、`模板副本.pptx`、`render/`、填充脚本。交付时只交最终正文、补充表和用户要求的其他文件。
- 模板是技能自带资产，以本技能目录为基准：`assets/人形机器人方案_PPT模板_V1.0.0.pptx`（23 页、16:9，含母版、BOM、场景图）、`assets/项目现场调研_Excel模板_V1.0.0.xlsx`。
- 每次出稿先复制模板副本再改，`assets` 内文件保持原样，回归时用它核对「原模板未发生变化」。

## 读入材料

- **调研表**（`现场调研` 工作表）：第 4–10 行是项目公共信息（客户名称、项目名称、地址、行业、导入时间、联系人、项目目标）；第 11 行起按「工位编号」往下读到表尾，多工位是整段复制到表尾，所以按字段名取值而不是固定行号。`物料明细` 第 5 行起按物料编号取尺寸、重量、载具、材质。
- **视频**：`ffmpeg -ss <秒> -i <视频> -frames:v 1 -q:v 2 <输出.jpg>`，覆盖动作开始、交接、结束与异常；时间点写进内部稿和图片页备注。整片只有 30–60 s 时，明确写「未覆盖完整循环」。
- **模板 / 历史方案**：只用 python-pptx 读结构，先 `python3 scripts/dump_template.py <pptx>` 导出页位与形状清单再动手，不按页号猜。
- **产品、报价与案例**：优先读本次附件和项目内 `参考资料/` 四个子目录；缺目录在内部稿记缺项，用现有证据做条件化分析。

## 执行链路

```bash
# 1) 摸清模板页位
python3 scripts/dump_template.py "assets/人形机器人方案_PPT模板_V1.0.0.pptx"

# 2) 按 shape_id 回填内容（自写 fill 脚本放在 _方案工作/<项目>/）

# 3) 固定页位语义校验
python3 scripts/check_ppmt_layout.py --output "<评审稿.pptx>" --cover "客户名 · 项目名" \
    --template-timeline --template-scenes --standard-bom

# 4) 逐页渲染，Read 看图后才能判定校验完成
python3 scripts/render_pages.py --pptx "<评审稿.pptx>" --out-dir "_方案工作/<项目>/render" --dpi 100

# 5) 客户补充信息表
python3 scripts/make_supplement_xlsx.py --input issues.json --output "客户名_项目名_W01_客户补充信息表.xlsx"
```

改一页就只重渲改动页及相邻页（`--pages 5` 或 `--pages 20-21`），改多页再全量。

## python-pptx 改稿要点

**换字保留原格式**：不要在 shape 上直接赋 `text`，会清掉字号与颜色。改第一个 run 的文字，删掉其余 run 与多余段落。

```python
def set_text(shape, text):
    tf = shape.text_frame
    p = tf.paragraphs[0]
    p.runs[0].text = text
    for r in p.runs[1:]:
        r._r.getparent().remove(r._r)
    for extra in tf.paragraphs[1:]:
        extra._p.getparent().remove(extra._p)
```

多行内容按段落逐条设置，每段复用原段落格式；确实需要更多段落时，深拷贝已有 `<a:p>` 再改字。

**中西文分设字体**：`run.font.name` 只写西文，中文要同时写 `<a:ea>`，否则中文回落主题字体。

```python
from pptx.oxml.ns import qn

def set_font(run, ea='微软雅黑', latin='Arial'):
    rPr = run._r.get_or_add_rPr()
    run.font.name = latin
    el = rPr.find(qn('a:ea'))
    if el is None:
        el = rPr.makeelement(qn('a:ea'), {})
        latin_el = rPr.find(qn('a:latin'))
        latin_el.addnext(el) if latin_el is not None else rPr.append(el)
    el.set('typeface', ea)
```

**动作页成对续页**：python-pptx 没有复制页 API，用深拷贝形状树并重映射关系 ID，图片才不会丢（本模板已验证，复制后 6 张现场图正常渲染）。

```python
import copy
from pptx.opc.constants import RELATIONSHIP_TYPE as RT

def duplicate_slide(prs, src_slide):
    new = prs.slides.add_slide(src_slide.slide_layout)
    for sh in list(new.shapes):
        new.shapes._spTree.remove(sh._element)
    for sh in src_slide.shapes:
        new.shapes._spTree.append(copy.deepcopy(sh._element))
    rid_map = {rid: new.part.rels.get_or_add(rel.reltype, rel._target)
               for rid, rel in src_slide.part.rels.items()
               if rel.reltype != RT.NOTES_SLIDE and not rel.is_external}
    R = '{http://schemas.openxmlformats.org/officeDocument/2006/relationships}'
    for el in new.shapes._spTree.iter():
        for attr, val in list(el.attrib.items()):
            if val in rid_map and attr.startswith(R):
                el.set(attr, rid_map[val])
    return new
```

复制页追加在末尾，需要移到目标位置时按页序重建；复制后先渲染确认图片、卡片底框、编号都在。

**表格**：`cell.text = ...` 会重置单元格格式。用 `cell.text_frame.paragraphs[0].runs[0].text` 改字；加行时深拷贝已有 `<a:tr>`，别整表重建（BOM 列宽、分组、跨页编号依赖原表结构）。

**图片替换**：保持原 shape 的 left/top/width 与比例，用 rId 重绑 `blipFill.blip` 的 `r:embed`；不要把不同比例的现场图硬拉伸。

**文本溢出**：模板很多文本框是 `wrap="none"` + `spAutoFit`，预览端会按文字宽度重算并整体位移。批量关掉这类框的 autofit，并给窄框（封面日期、封底致谢行）留出宽度，不要靠缩字号解决。

## 字体与预览差异

Noto Sans CJK 与微软雅黑宽度不同，窄框里的日期行（如封面「2026 年 11 月」）在预览里可能断成两行，属预览差异，不据此改文案或字号；真实内容溢出、被图形压住、表格挤成一团才是必须修的。用户要求像素级确认时，说明本地预览用了替代字体。

## 交付

- 用 `present_files` 按绝对路径交付最终 pptx 与 xlsx；中间稿、渲染图、模板副本不交付。
- 交付说明写清：所用模板与版本、页数、缺项与待确认数量、已完成哪些校验（语义校验 + 逐页渲染）、替代字体这一预览限制。

## 在线幻灯片

用户明确要飞书在线协作版时：本技能只出**逐页制作稿**（每页标题、结论、图表素材、来源、待确认项），排版交 `ppt` 技能；交付时说明在线版不复用本次 pptx 的版式锁定结论。是否经过转换校验、最终交付的是制作稿还是在线幻灯片，按当次实际交付如实写明。

## 与其它技能的分工

| 场景 | 走法 |
|---|---|
| 读/写调研表、生成补充表 xlsx | openpyxl 按原格式读写；用户明确要在线协作表格时才转 `sheet` 技能，转后原表格式不再保证 |
| 飞书在线幻灯片 | 本技能出制作稿，`ppt` 技能排版 |
| 视频关键帧 | 本机 ffmpeg 优先；需要更复杂理解时用视频类技能 |
| 结构完整性抽查（能否打开、页数、字体名） | `verifier-hub` 或 `scripts/check_ppmt_layout.py`；视觉问题必须看渲染图 |

## 已知坑

- `soffice` 必须带 `--headless`；目标路径已有同名 PDF 在转换会失败，重跑前先清输出目录。
- 模板约 10 MB，主要来自母版图片；每页塞大图会让文件迅速膨胀，同一张现场图不要在多页重复嵌入。
- `check_ppmt_layout.py` 按页面标题定位页位，续页后仍可用；但它假定报价页两页、本体组至少三页，页数结构变化时报错属预期。
- 模板 1.0.0 正文没有 `{{字段}}`/`##提示##` 标记，填页靠形状名与页位，先 dump 再改。
- 直接往固定宽度卡片塞长文案会溢出，渲染图一眼可见；先压文案，不要先缩字号。
