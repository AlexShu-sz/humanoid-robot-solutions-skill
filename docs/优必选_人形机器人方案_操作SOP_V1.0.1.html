人形机器人方案自动化流程

首次出稿只需两步。填好现场调研 Excel，再把 Excel 和 PPT 模板一起发给 AI。有现场视频、照片或图纸时也一并上传。

操作步骤

  1. 1填好现场调研 Excel

    输入
    空白《项目现场调研_Excel模板_V1.0.0.xlsx》、已有项目资料。
    怎么做
    填客户、项目、工位、物料、人工动作、节拍和改造目标。数字写明单位，缺失项填「待确认」。
    输出
    填好的现场调研 Excel。

  2. 2上传文件，发一句出稿指令

    输入
    填好的 Excel、《人形机器人方案_PPT模板_V1.0.0.pptx》，以及手头已有的现场视频、照片或图纸。
    怎么做
    在支持文件上传和生成 PPTX 的 AI 中启用方案技能，把资料上传到同一对话，发送下方指令。
    输出
    中文命名的可编辑方案评审稿 PPTX。若有关键缺项，附客户补充信息表 Excel。

    发给 AI 的指令

    请使用人形机器人解决方案技能，根据我上传的现场调研 Excel，按上传的 PPT 模板生成可编辑的人形机器人方案评审稿。若有现场视频、照片或图纸，请结合资料核对。待确认信息请注明，影响方案判断的问题请另外整理成客户补充信息表。交付文件默认用中文命名。

  3. 3下载并检查方案初稿

    输入
    AI 生成的 PPTX，以及按需提供的补充信息表。
    怎么做
    打开 PPT，核对客户和项目名、关键数据与模板格式。确认待核字段已注明，整理需要补充或修改的内容。
    输出
    核对过的评审稿，或一份待补充和修改的清单。

  4. 4有补充或修改时，回传资料并更新

    输入
    已回填的补充表、新资料或修改意见。
    怎么做
    在原对话上传回复，让 AI 按问题编号更新对应页面。换对话时，一并上传上一版 PPT 和本次补充资料。
    输出
    修订后的可编辑 PPTX，按需附更新的客户补充表。

启用方案技能后，需求核验、参考匹配、章节规划和模板填充会在出稿过程中完成。存在影响方案方向的关键信息缺口时，AI 可能先集中询问。
