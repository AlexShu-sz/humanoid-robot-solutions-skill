优必选 · 工业人形机器人

人形机器人方案自动化流程

装一次技能，之后每次只需上传现场调研 Excel。模板可以不传，技能自带品牌模板；有现场视频、照片或图纸就一并上传，AI 会拿来核对动作、设备和空间。出稿同时会给一份客户补充信息表，缺什么、为什么影响方案，都写在表里。

这次要什么、给什么

你要提供 输入

  • 必需 现场调研 Excel：《项目现场调研_Excel模板_V1.0.0.xlsx》或同字段的逐项版，写清项目信息、工位编号、物料、人工动作、节拍与改造目标。
  • 可选 PPT 模板：本次上传即优先用这份；不传则用技能自带 assets/人形机器人方案_PPT模板_V1.0.0.pptx。
  • 可选 现场视频 / 照片 / 图纸：用于核对动作顺序、设备接口、空间尺寸；视频会按时间点抽帧比对。
  • 可选 历史方案、参考资料：本体、末端、历史解决方案、报价四类，用于选型与报价参考。
  • 可选 上一版评审稿 + 已回填补充表：第二轮更新时一起给，按问题编号回填。

你会拿到 输出

  • 评审稿 PPTX（默认交付）：可编辑文本、表格、图形，中文命名 客户名_项目名_人形机器人方案评审稿.pptx。
  • 客户补充信息表 XLSX：影响方案判断的问题逐条列出，客户填写列留空待回填，默认 客户名_项目名_工位编号_客户补充信息表.xlsx。
  • 页面内的待确认标注：每条待确认写在对应正文、图示或表格行，不放页底小字，也不只写在备注里。
  • 交付说明：用了哪份模板、共几页、多少项待确认、做过哪些校验。

不交付：内部项目稿（内部项目稿.md）、逐页渲染图、模板副本。这些留在工作目录供复核，不占交付清单。

安装技能

技能包从 最新发布 下载，同一个 Release 里有两个附件：…_doubao.zip 与 …_chatgpt.zip，技能名统一是 industrial-robot-solution。

豆包工作 · 本机安装

带模板的包，适合自己和固定同事用

  1. 下载 doubao 包（约 9.9 MB，含两份模板）。
  2. 把 ZIP 发到对话里，附一句「安装这个技能」；技能会解压到工作区的 .user_skills/industrial-robot-solution。
  3. 装完直接在同一个对话里发下面的出稿指令，不必再上传模板。
  4. 更新版本时重复上面两步，覆盖同名目录即可，模板与规则一起换新。

带模板的包只适合本机安装：模板单文件约 9.8 MB，超过开放平台单文件 2 MB 上限，不能上传到控制台。

豆包开放平台 · 企业内上架

发一次包，同事在「企业提供」里自己装

  1. 先出不含模板的包：整包约 0.1 MB，符合 16 MB / 2 MB 限制。
  2. 控制台左侧 技能列表 → + 创建技能 → 选 企业专属。发布范围首次确定后不能切换，公开上架要先过企业资质认证。
  3. 上传资源：拖入 ZIP。限制是压缩包 ≤ 16 MB、条目 ≤ 1024 个、单文件解压 ≤ 2 MB、解压总量 ≤ 16 MB。
  4. 等平台解析出名称、简介、图标、版本号并校验通过。这几项来自包内，控制台改不了，要改只能重打包再传。
  5. 完善技能信息：选企业分类，版本号用三段式（1.0.2），可用范围选企业内全员或指定成员。
  6. 提交版本 → 企业管理员审核 → 通过后出现在豆包工作 「企业提供」 列表，点安装、启用即可。
  7. 模板另发：包内没有 assets/，把模板在对话里上传一次，或放到团队共享目录。
python3 build_skill.py --platform doubao --no-assets # 出控制台上传包，不含模板 python3 build_skill.py --version 1.0.2 # 出两个完整包，用于本机安装与 Release
ChatGPT

用同一个 Release 的 chatgpt 包

  1. 下载 chatgpt 包，按该平台加载技能的方式装好。
  2. 该平台的执行说明还没写，包内没有 references/平台执行说明.md 时，技能按共用规则和宿主现有能力执行，交付前会说明缺这一步。
  3. 豆包侧的差异（交付方式、在线幻灯片边界）不影响共用规则，两边跑同一套业务判断。

四步流程

  1. 1填好现场调研 Excel

    输入
    空白《项目现场调研_Excel模板_V1.0.0.xlsx》、已有项目资料。
    怎么做
    填客户、项目、工位编号、物料、人工动作、节拍和改造目标。数字写明单位，缺失项填「待确认」，不要留空。
    输出
    填好的现场调研 Excel。

  2. 2上传资料，发一句出稿指令

    输入
    填好的 Excel；模板、现场视频、照片、图纸、历史方案按需附上。
    怎么做
    资料放进同一对话，发下面任一条指令。有模板就用第一条，没有就用第二条走自带模板。
    输出
    中文命名的可编辑评审稿 PPTX；影响方案判断的缺项整理成客户补充信息表 XLSX。

    指令 A · 上传了模板

    请使用人形机器人解决方案技能，根据我上传的现场调研 Excel，按我上传的 PPT 模板生成可编辑的人形机器人方案评审稿。现场视频、照片或图纸请一并核对，与表格冲突的地方在对应页面注明。待确认信息写在相关正文或表格行，影响方案判断的问题另外整理成客户补充信息表。交付文件默认用中文命名。

    指令 B · 不上传模板，用技能自带品牌模板

    请使用人形机器人解决方案技能，根据我上传的现场调研 Excel 生成可编辑的人形机器人方案评审稿，版式用技能自带的品牌模板。现场视频、照片或图纸请一并核对，与表格冲突的地方在对应页面注明。待确认信息写在相关正文或表格行，影响方案判断的问题另外整理成客户补充信息表。交付文件默认用中文命名。

  3. 3下载并检查初稿

    输入
    评审稿 PPTX、客户补充信息表 XLSX、交付说明。
    怎么做
    按下面六项核对。有问题的写进补充表或直接列为修改意见，不用自己改 PPT。
    输出
    核对过的评审稿，或一份待补充、待修改清单。

  4. 4回填补充表，让 AI 更新

    输入
    客户回填后的补充表、新资料或修改意见。
    怎么做
    在原对话上传回填表，让 AI 按问题编号更新对应页面。换对话时，把上一版 PPT、内部项目稿和补充表一起给。
    输出
    修订后的 PPTX、更新后的补充表，以及「哪些页面因补充信息变了」的说明。

检查初稿看这六项

封面与命名

客户名、项目行逐字对，工位编号留在正文和补充表；文件名与交付说明一致。

动作对应

人工动作页与机器人等效页的 01–06 编号、名称、顺序一一对应；三色角色标签（人工保留／机器人执行／系统或设备）贴对位置。

时间轴与场景图

没有项目排期时沿用模板五段周次并标「计划参考」；工业应用场景图未被替换或移位。

配置与报价

表头、分组、标准项目名称与顺序不变，编号跨页连续；软件组只留「软件和场景开发」。

待确认与可读性

每条待确认在正文可见；没有页底小字注释；没有文字超出框、图片裁切、数字与单位拆行。

机型与子系统

本体型号副标题、末端示意、工位布局与现场实际相符；与视频不一致处已标为拟改造或待确认。

前四项有固定页位校验脚本兜底，后两项靠逐页渲染看图。这两步由技能在出稿时完成，你只需要核对结论。

 业务判断两边一致，差异只落在模板取用、脚本执行和交付方式。

三条边界

不编数据。型号、价格、节拍、案例都来自本次资料或可访问的参考资料；缺就记缺项，不用估算值冒充实测。区分状态。「已确认／现场观察／工程假设／待确认／冲突」分开写，文件日期新或视频里看得见都不等于客户确认。只交能改的稿。交付物必须是可编辑 PPTX，不是图片拼版或只读预览。
