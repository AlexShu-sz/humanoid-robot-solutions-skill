优必选 · 工业人形机器人

人形机器人方案自动化流程

装一次技能，以后每次只上传现场调研 Excel。模板不用传，技能自带品牌模板；有现场视频、照片或图纸一并上传，会用来核对动作、设备和空间。

给什么、拿什么

你要给 输入

  • 现场调研 Excel（必需）：空白模板或同字段的逐项版，写清项目信息、工位编号、物料、人工动作、节拍和改造目标，数字带单位。
  • 现场视频、照片、图纸（可选）：核对动作顺序、设备接口和空间尺寸。
  • 历史方案、参考资料（可选）：本体、末端、历史解决方案、报价四类。

你会拿到 输出

  • 评审稿 PPTX：可编辑文本、表格、图形，中文命名 客户名_项目名_人形机器人方案评审稿.pptx。
  • 客户补充信息表 XLSX：影响方案判断的问题逐条列出，客户填写列留空待回填。
  • 交付说明：用的哪份模板、共几页、多少项待确认、做过哪些校验。

内部项目稿、渲染图、模板副本只留工作目录，不交付。

安装技能

豆包工作 · 本机安装

  1. 从最新 Release 下载 doubao 包（约 9.9 MB，内含 PPT 与 Excel 模板）。
  2. 把 ZIP 发进对话，附一句「安装这个技能」，会解压到 .user_skills/industrial-robot-solution。
  3. 装好就能直接发下面的出稿指令，不必再上传模板。
  4. 更新版本时重复前两步，覆盖同名目录，模板与规则一起换新。

四步流程

  1. 1填好现场调研 Excel

    输入
    空白调研表、已有项目资料。
    怎么做
    填客户、项目、工位编号、物料、人工动作、节拍和改造目标；缺的填「待确认」，不要留空。
    输出
    填好的调研 Excel。

  2. 2上传资料，发一句指令

    输入
    填好的 Excel；视频、照片、图纸按需附上。
    怎么做
    资料放进同一对话，发下面的指令。想用别的模板，把模板一起传，指令里加一句「按我上传的模板生成」。
    输出
    中文命名的评审稿 PPTX；影响方案判断的缺项整理成补充信息表 XLSX。

    出稿指令

    请使用人形机器人解决方案技能，根据我上传的现场调研 Excel 生成可编辑的人形机器人方案评审稿。现场视频、照片或图纸请一并核对，与表格冲突的地方在对应页面注明。待确认信息写在相关正文或表格行，影响方案判断的问题另外整理成客户补充信息表。交付文件默认用中文命名。

  3. 3下载并检查初稿

    输入
    评审稿 PPTX、补充信息表、交付说明。
    怎么做
    按下面几项核对，有问题写进补充表或列为修改意见，不用自己改 PPT。
    输出
    核对过的评审稿，或一份待补充、待修改清单。

  4. 4回填补充表，让 AI 更新

    输入
    客户回填后的补充表、新资料或修改意见。
    怎么做
    在原对话上传回填表，按问题编号更新对应页面；换对话时把上一版 PPT、内部项目稿、补充表一起给。
    输出
    修订后的 PPTX，以及「哪些页面因补充信息变了」的说明。

检查初稿看这几项

  • 封面与命名：客户名、项目行逐字对，工位编号留在正文和补充表。
  • 动作对应：人工动作与机器人等效页的 01–06 编号、名称、顺序一致，三色角色标签贴对。
  • 时间轴与场景图：无排期时沿用模板五段周次并标「计划参考」；场景图未被替换。
  • 配置与报价：表头、分组、标准项目名称与顺序不变，编号跨页连续。
  • 待确认与可读性：每条待确认在正文可见；无页底小字、文字超框、图片裁切、数字与单位拆行。
  • 机型与子系统：型号副标题、末端示意、工位布局与现场相符；与视频不一致处已标为拟改造或待确认。

这几项技能在出稿时已校验一遍：固定页位用脚本查，可读性逐页渲染看图。你只需要核对结论。

两条硬约束

不编数据。型号、价格、节拍、案例只用本次资料或可访问参考资料里的，缺就记缺项。只交能改的稿。交付物必须是可编辑 PPTX，不是图片拼版或只读预览。
